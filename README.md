# JSONPack

Convert videos and GIFs to lightweight animated formats.

Supports MP4, GIF, WebM, MOV.

---

## Output formats

- Telegram Style (TGS) - for messengers like Telegram, VK
- Lottie JSON - for Flutter, iOS, Android, Web
- SpriteSheet + JSON - for games (Unity, Cocos)
- CSS Animation - for websites
- Android (Java) - for native Android
- iOS (Swift) - for native iOS
- React - for React applications

---

## Download

Get the latest .exe from Releases section.

Just download and run, no installation needed.

---

## How to use

1. Open JSONPack.exe
2. Select a video or GIF
3. Choose output format and settings
4. Click "Сжать и создать JSON"
5. Get your animation files in the output folder

---

## Build from source
git clone https://github.com/ТВОЙ_НИК/JSONPack.git

cd JSONPack

pip install -r requirements.txt

python main.py

Build .exe: py -m PyInstaller --onefile --windowed --name="JSONPack" main.py
