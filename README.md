# AnimaLean

Convert videos and GIFs to lightweight animated formats.

Currently in beta. Tested on MP4, GIF, WebM, MOV.

---

## Output formats

- Telegram Style (TGS) - for messengers
- Lottie JSON - for Flutter, iOS, Android, Web
- SpriteSheet + JSON - for games
- CSS Animation - for websites
- Android (Java) - for native Android
- iOS (Swift) - for native iOS
- React - for React applications

---

## Download

Get the latest .exe from Releases section.

Beta version - report issues if you find them.

---

## How to use

1. Open JSONPack.exe
2. Select a video or GIF
3. Choose output format and settings
4. Click "Сжать и создать JSON"
5. Get your animation files

---

## Build from source
git clone https://github.com/suptewme/AnimaLean.git
cd JSONPack
pip install -r requirements.txt
python main.py
